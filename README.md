## 🚀 Getting Started

### Prerequisites

Make sure Python is installed on your system.

Check your Python version:

```bash
python --version
```

or:

```bash
python3 --version
```

### Clone the Repository

```bash
git clone https://github.com/rudrapratap17003-coder/python.git
```

Navigate into the repository:

```bash
cd python
```

Run any Python file:

```bash
python filename.py
```

For example:

```bash
python conditional.py
```
